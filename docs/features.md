# 功能范围

以下说明对应 PxBoard 核心 `0.3.0` 及当前官方插件。模式决定默认安装组合和使用入口，业务能力取决于实际安装并启用的插件。

## 核心与使用界面

| 模块         | 功能                                                                                                             |
| ------------ | ---------------------------------------------------------------------------------------------------------------- |
| 初始化与模式 | 自用、分享、商业运营；按可信插件源中的组合解析依赖、后台安装启用、显示状态、失败重试；安装成功后切换当前模式     |
| 身份与权限   | 管理员与普通用户、登录退出、密码修改、密码找回、只读及读写 API 密钥、会话撤销                                    |
| 插件管理     | 在线源注册与启停、当前平台筛选、依赖安装、组合安装、权限展示、启停、重启、卸载、升级恢复与可选 Ed25519 发布签名  |
| 运行与记录   | 独立插件进程、插件数据命名空间、持久事件投递、失败重试、操作记录                                                 |
| 管理后台     | 按已安装插件组织导航、资源列表、筛选、排序、分页、表单、导出、二维码、深浅主题和移动端导航                       |
| 用户前台     | `/user` 独立导航；自身套餐权益、流量与到期、订阅、订单、余额、工单、帮助和推广；只显示已启用且当前模式适用的功能 |
| 商业公开首页 | 未登录访客查看公开在售套餐、价格、额度和期限，登录或注册后继续选择的套餐                                         |

管理员默认进入后台，可通过“用户前台”查看自己的使用入口。普通用户进入前台。前台使用真实业务接口，不以支付返回页参数代替服务端订单状态。

| `payments`       | Stripe Checkout 和易支付、渠道管理、支付回调签名、金额与币种检查、重复回调处理、支付流水                                         |

安装商业组合后仍需创建套餐、配置收款渠道并接入真实节点。安装插件不会生成虚构套餐、支付商户、节点负载或用户订单。

## 套餐与账户权益

套餐期限统一使用 `durationUnit` 与 `durationValue`，分别表达按天、按日历月和长期。账户权益与商品定义分开存储，编辑商品不会重写已经购买的订单快照。

流量额度 `quotaGiB` 与 `unlimited` 分开表达。`quotaGiB=0` 且 `unlimited=false` 表示没有可用流量；不限流量需要显式启用。新建自用或分享工作空间时，仅为尚无账户的管理员建立默认长期不限流量账户，已有账户与既有权益保留。

迁移账户保留原流量使用基线、到期与已识别的重置规则，包括重置日、按到期日重置、年度重置和源时区。SSPanel 的等级和等级到期单独保存。订阅令牌可保留，但订阅地址采用 PxBoard 自己的路径。

## 支付、余额与推广

用户创建订单后，可选择余额支付或已启用的在线支付渠道。在线支付返回 `/user/orders`，前台继续读取服务端订单状态；收到服务端确认并完成权益发放后才显示开通结果。未配置在线渠道时，不会模拟支付成功。

金额以人民币整数分存储和传递，界面以元输入和显示。订单保存购买时的套餐与金额快照。相同购买请求可以通过稳定的 `requestId` 防止重复创建订单；流量、权益、充值和佣金分别使用稳定操作标识防止重复入账。

退款操作为“退回余额”：撤销对应订单的权益，再将金额记入用户余额。有更新的权益订单时，先处理较新的订单。充值订单不通过再次入账的方式退款。

推广支持推荐链接、推荐人数、个人折扣、个人返佣比例、首次购买或持续返佣、冻结周期、可用佣金、转入余额和现金提现申请。用户可撤回符合状态要求的申请，管理员审批并登记打款。现金转账由运营方在外部执行；面板不会自动向用户银行或支付账户打款。

## 节点接入与监控

| 接入方式                   | 配置与运行范围                                                                                                                                    |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| NodeRS                     | PxBoard 自有机器接口、多节点、用户与独立连接凭据、配置同步、持久流量批次、在线账户及主机状态上报；具体协议能力由所使用的 NodeRS / Aerion 版本决定 |
| 官方 `px-agent` + Xray     | 当前提供 TCP 下的 VLESS、VMess、Trojan、Shadowsocks 配置，可选 TLS 文件证书                                                                       |
| 官方 `px-agent` + sing-box | 当前提供 VLESS、VMess、Trojan、Hysteria 2 配置；流量查询使用 V2Ray API，需要支持该功能的内核构建及查询工具                                        |

官方代理会在替换运行配置前调用内核的配置检查。修改配置可能重启相应内核并中断现有连接。用户暂停、额度变化和审计阻断按同步周期生效，默认同步间隔为 30 秒。

`nodes` 的状态页根据最后心跳判断在线：120 秒内收到心跳视为在线；已停用、从未接入、离线与运行异常分别显示。普通用户只可查看自己有权使用的节点，管理员可以查看机器、心跳、错误与已上报的资源用量。

CPU、内存、磁盘、交换空间和在线账户来自实际节点上报。目前这些主机负载数据由 NodeRS 提供；没有上报的数据保持为空。状态页不执行公网连通性探测、客户端延迟测试或吞吐量测试。

## 流量审计

审计处理连接目标元信息，不解密 TLS 或收集通信正文。官方 Xray 代理可以读取访问日志并产生审计命中；sing-box 可以接收阻断规则，当前没有将其访问日志转换为审计命中记录的采集器。NodeRS 的流量统计与在线账户上报也不等同于目的地址审计采集。

IP 网段规则需要实际目的 IP，不能用猜测的域名解析结果代替。规则能否在节点端阻断，取决于所使用的节点代理和内核配置能力。命中记录默认保留 7 天。

## 数据迁移

迁移分为冻结快照、预览与整批提交。用户、原密码信息和业务记录在同一事务中写入；暂存不完整、目标冲突或关键数据无法识别时阻断。已提交任务再次执行不会重复写入。未映射的旧字段与表保留归档，历史订单和支付信息不会触发重新扣款或开通。

SSPanel 各分支的商品开通规则差异较大，商品内容与购买限制保留，但先设为停售供核对。遇到尚不能执行的 V2Board / Xboard 限售或续费规则，也先保留并停售。节点与机器为可选迁移项，证书和节点本地配置仍需单独核对。

原编码密码和已识别的动态验证码配置可以迁移；动态验证码密钥缺失或无法识别时不会自动关闭验证。详细字段、来源差异、重试与恢复方式见 [官方迁移文档](../../PxBoard-Plugins/docs/migration.md)。

## 当前边界

当前产品不承诺覆盖 Xboard、SSPanel 或 x-ui 的所有历史版本及功能。以下内容尚未提供：

- 自动扣费续订、Stripe Billing、按剩余时长精细折算的升降级、税务发票、原支付渠道自动退款或自动现金打款。
- 多币种结算、PostgreSQL、多实例共享运行器和插件的操作系统沙箱。
- 任意第三方前端脚本包的在线加载；第三方插件主要通过声明式页面扩展界面。
- 完整的代理链与路由编辑器；官方 `px-agent` 尚未提供与 NodeRS 相同的扩展传输和证书管理能力。
- 新用户自行开通及管理动态验证码的完整设置界面、邮箱验证码注册、复杂客服团队权限和完整登录风控。

外部节点、支付商户、SMTP 服务及证书需要使用运营方自己的实际配置。面板的账户状态、后台任务和支付流水可用于核对处理结果，但不能替代外部服务本身的可用性。
