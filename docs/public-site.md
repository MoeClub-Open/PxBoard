# 公开首页与搜索

商业模式的 `/` 是公开落地页，登录后仍可查看。从“进入账户”进入 `/user`；登录和用户前台均不提供管理地址。自用模式不开放商业落地页，所有应用页面默认禁止收录。

## 内容与管理

“站点设置”由官方 `branding` 插件提供。品牌信息管理名称、Logo、图标；“首页与搜索”管理首页标题、服务介绍、逐行的服务要点、页脚、搜索分享标题、摘要、分享图片及首页收录开关。首页标题留空使用站点名称；搜索标题留空使用首页标题；摘要留空使用服务介绍，仍为空则使用账户与订阅服务的简短描述。

首页只展示品牌介绍、可配置的服务说明以及登录／注册入口。套餐名称、价格、周期和流量额度仅登录后可见，服务端 HTML、公开快照和结构化数据都不包含套餐，不再提供匿名套餐目录。新购、续费与购买意图处理保留在用户前台。

首页使用左右分栏的品牌主视觉和装饰性网络插画，窄屏改为上下布局。插画不展示在线率、性能或虚构用户数据；颜色沿用现有深浅主题。登录入口集中在首屏，开放注册时显示注册入口，已登录时改为进入账户。

公开地址由服务端配置决定，不使用请求中的 Host 生成规范网址或分享链接。公开访问地址只能为 HTTP/HTTPS 站点根地址，例如 `https://panel.example.com`；已有启动参数 `-public-url` 仍优先于数据库设置。

## SEO 和分享

服务端直接返回首页标题和介绍 HTML；不依赖搜索引擎运行 JavaScript 获取公开内容。前端以同一份公开快照加载，公开正文与页面元信息保持一致。

首页提供 title、description、canonical、Open Graph、Twitter Card 和 WebSite 结构化数据。分享图片可填写 HTTPS 地址或本站绝对路径。文本经过模板转义，嵌入页面的数据使用安全 JSON 编码。

- `/robots.txt` 只允许收录商业首页及其静态资源，不列出独立管理地址。
- `/sitemap.xml` 只列出可收录首页，不包含用户、订单、订阅、登录或后台路径。
- 登录、注册、找回密码、初始化、用户前台、管理页面和接口带有禁止收录策略；前端路由切换也同步移除首页的 canonical 和分享信息。
- 自用模式、尚未完成初始化、未配置公开地址、首页插件不可用或关闭首页收录时，不输出可收录页面记录。
- 不存在的应用路径返回 404，避免任意路径都变成状态为 200 的登录页面。注册的订阅等公开路由继续优先处理。

不向搜索引擎或第三方站长服务自动提交站点。分享信息可以立即从源代码读取，搜索收录仍由对应搜索引擎决定。

## 插件接口

核心提供 `GET /api/v1/site` 返回公开快照，不包含任何管理地址、用户标识、凭据或任何套餐数据。HTML、站点地图和 robots 策略统一使用同一来源。

插件可在声明中注册首页提供方：

```json
{ "site": { "path": "/_site", "modes": ["business"] } }
```

核心选择首个已启用、状态正常且匹配模式的提供方。一个模式应仅启用一个首页提供方。`GET /_site` 接收核心服务身份及 JSON 请求体 `SiteContext`，包含名称、模式、公开地址、注册状态和 `content` 标记。正文为空的元数据请求应避免读取商品等业务目录。响应为标准 `data` 包裹的 SDK `PublicSite`。

`PublicSite` 包含名称、标题、摘要、图标、分享图片、收录意愿、服务端 HTML 及公开数据。核心负责最终收录条件和 HTTP 输出，不管理套餐或首页文案。官方品牌插件使用 `renderer=storefront` 和配套数据呈现交互式页面；其他可信插件可返回静态 HTML，前端保留其公开内容。插件 HTML 属于受信任的已安装程序输出，不能将用户输入未经转义拼入 HTML。

官方品牌插件的首页和 SEO 与既有品牌数据使用同一配置，不调用商业目录，没有商业插件依赖。核心和品牌插件应一起升级到同一发布批次；开发版本继续保持 `0.0.1`。
