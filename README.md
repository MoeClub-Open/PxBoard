# PxBoard

基于插件的代理管理面板，支持自用、公益分享和商业运营。核心提供账号权限、插件安装与运行、持久事件、数据存储和界面容器；品牌、注册、节点、访问权益、订阅、兑换码、推广、订单、支付、流量审计与用户服务由独立插件提供。

首次选择使用方式后，面板从配置的插件源读取安装组合，自动安装依赖并启用对应功能。商业模式提供公开套餐首页、独立用户前台和管理员后台。核心版本为 `0.4.0`，插件接口版本为 `1.0`。

## 使用方式

| 模式     | 默认功能                                               | 使用入口                                                        |
| -------- | ------------------------------------------------------ | --------------------------------------------------------------- |
| 自用     | 品牌、节点、访问账户、订阅                             | 管理后台；为尚无访问账户的管理员创建长期、不限流量的默认账户    |
| 公益 / 分享 | 自用功能、用户注册、兑换码、流量审计                | 管理员配置兑换码，用户注册后兑换权益并使用订阅                  |
| 商业运营 | 品牌、用户注册、节点、订阅、套餐订单、余额、支付、审计与用户服务 | 访客查看公开套餐，用户在 `/user` 购买和使用服务，管理员管理运营 |

安装组合定义在独立插件源中。安装过程显示逐项状态，失败后可以调整来源并重试。推广返佣与第三方登录均为可选插件，不随任何模式默认安装；商业站点也可单独安装兑换码。切换模式保留已经安装的其他插件和业务数据，关闭某项功能应停用对应插件；套餐、支付渠道与节点服务器仍需按实际业务配置。详见 [使用模式与初始化](docs/modes.md)。

## 功能

- 访问账户支持独立额度、到期、限速、设备限制、节点分组与周期重置；不限流量使用独立标志，零额度不会自动变成无限。
- 品牌、普通注册、兑换码、推广返佣分别配置；公益站可只提供注册、兑换和订阅，无需商业交易或推广功能。
- 商业用户可选购套餐、使用余额或在线支付，查看订单、余额记录和订阅链接；可按需添加工单、使用文档、公告与推广返佣。
- 节点支持 NodeRS 原生机器接口，以及官方 Xray / sing-box 节点代理。状态页按真实心跳与上报数据展示在线状态、负载和在线账户。
- 流量审计支持域名、关键词、正则、IP 网段和协议规则，可记录、下发阻断或暂停账户。
- 官方迁移插件分别导入 SSPanel、V2Board、Xboard 的用户、套餐、余额和订阅，提供预览、冲突检查与整批提交；未转换的原表保留归档。

具体能力、协议范围和未实现项见 [功能范围](docs/features.md)。

## 本地启动

需要 Go 1.26+、Node.js 24+ 和 pnpm。将三个仓库放在同一父目录，在插件源仓库构建本机安装包并启动源服务：

```sh
cd PxBoard-Registry
go run ./cmd/publish
go run ./cmd/registry
```

另开终端，在主仓库构建界面并启动面板：

```sh
cd PxBoard
pnpm --dir web install
pnpm --dir web build
go run ./cmd/pxboard -plugin-source http://127.0.0.1:8091/index.json
```

打开 `http://127.0.0.1:8080`，选择模式、创建管理员并等待对应功能安装完成。以上开发命令使用本机插件源；发布程序默认使用[官方在线插件源](https://raw.githubusercontent.com/MoeClub-Open/PxBoard-Registry/main/index.json)，无需另外启动源服务。没有预设管理员账号或密码。

生产部署、自建插件源、HTTPS、备份和节点安装见 [部署文档](docs/deployment.md)。
